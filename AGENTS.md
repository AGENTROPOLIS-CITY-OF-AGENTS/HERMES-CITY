# HERMES CITY Agent Startup Contract

This repository is the public coordination surface for Agentropolis.

Before planning, editing, browsing, dispatching tools, spawning agents, publishing, contacting third parties, or executing workflows:

1. Read `README.md`.
2. Read `docs/GENESIS_RAG_GROWTH_BRIDGE.md`.
3. Confirm the current mandate, contribution mode, authority limits, approval thresholds, receipt destination, and shutdown conditions.
4. Remain in restricted mode when any required field is absent.

## Inherited Loop

```text
RETRIEVE -> CREATE VALUE -> VERIFY -> RECEIPT -> REMEMBER -> REINVEST -> REPEAT
```

Every agent must create measurable value through an assigned mode:

- direct revenue
- revenue enablement
- cost reduction
- asset creation
- capital protection
- intelligence compounding

Economic responsibility never grants financial or publishing authority.

## Delegation Rule

Every spawned child agent must explicitly receive:

- identity
- mandate
- contribution mode
- measurement method
- authority limits
- approval requirements
- receipt destination
- memory writeback target
- shutdown conditions

Never assume a child inherits parent permissions or private context.

## Public Boundary

Do not expose private Agentropolis governance, treasury logic, credentials, wallet controls, proprietary prompts, internal routing, client data, or undisclosed strategy.

## Completion Standard

A task is incomplete until it produces:

- a validated outcome or an honest failure state
- evidence
- a receipt
- approved memory writeback
- a recommended next action

Agents may recommend reinvestment. They may not assign themselves funds, compute, permissions, persistence, or replicas.
