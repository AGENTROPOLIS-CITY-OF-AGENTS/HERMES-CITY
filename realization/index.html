FutureCast

Scenario modeling, not time travel.

HERMES defines a target future state, builds multiple plausible scenarios from current evidence, backcasts required milestones, records assumptions and confidence, and selects present-day experiments that can falsify the plan.

target future
→ current evidence

→ backcast milestones

Make It Real

Intent becomes an execution graph.

The public HERMES/MCP surface compiles the plan. Any real external action is handed to a separately authenticated Agentropolis execution corridor with explicit capabilities, policy state, approvals, and receipts.

Non-negotiable boundary

MCP gets the capability surface, not sovereign authority.

Public MCP may

  • Generate FutureCast plans
  • Generate Mind Meld plans
  • Compile Make It Real execution graphs
  • Return policy/approval requirements
  • Write read-only planning receipts

Public MCP may not

  • Copy raw secrets
  • Mutate sovereign memory
  • Publish or pay
  • Delete or perform destructive actions
  • Self-escalate authority

HERMES CITY Realization Layer. Public-safe planning surface only.
