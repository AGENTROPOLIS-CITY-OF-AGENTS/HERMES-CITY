# DeepSeek V4 Flash 0731 + MiniMax H3 Routing

HERMES CITY integrates these as two replaceable workers behind the Model Council and Capability Bus.

## Route identities

### DeepSeek V4 Flash 0731

**Role:** temporary preferred Fast Worker and bounded Builder candidate while the Nous Portal promotion remains economically favorable.

Good routes:

- repository triage and summarization
- code and test drafts
- bounded terminal work in a sandbox
- structured extraction
- prompt and workflow compilation
- high-volume content variants
- district evaluation generation

Never grant elevated authority from price or benchmark claims alone. Production mutation, deployment, credentials, wallets, destructive actions and security-critical approval still require policy checks, validation and human approval.

### MiniMax H3

**Role:** asynchronous audiovisual execution capability.

Good routes:

- text, image and reference-driven video candidates
- character and product motion
- short-form cinematics
- lookbooks and campaign clips
- UI motion demonstrations
- audio-reactive or dialogue-driven media candidates

H3 receives a shot contract and governed reference manifest. It does not choose rights, consent, publication, campaign truth or final distribution.

## Router sequence

```text
mandate
  -> classify task and risk
  -> choose text/code worker or media capability
  -> resolve live provider model ID
  -> verify current price and availability
  -> apply district policy
  -> execute in bounded lane
  -> validate result
  -> write receipt
  -> request human approval when required
```

## Promotion rule

The reported 90% discount and seven-day duration are a temporary routing signal. HERMES must fetch the live Portal catalog entry before execution and must not assume the displayed alias, price or promotion is unchanged.

The reported Terminal-Bench 2.1 and cost-comparison claims are useful scouting signals, not automatic evidence for production adoption. Run Agentropolis district evals and compare **cost per accepted output**.

## Fallbacks

- DeepSeek unavailable, renamed, degraded or no longer economical: return to the standard Fast Worker or Builder council.
- H3 unavailable or rejected by rights or quality gates: route to another approved media provider or return the job for repair.
- Any silent provider substitution is forbidden for identity-sensitive media or elevated execution.
