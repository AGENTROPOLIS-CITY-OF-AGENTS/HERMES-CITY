# SUPER HERMES — HERMES CITY Capability Intelligence Office

SUPER HERMES is a core civic institution inside HERMES CITY.

It is not a separate city, an Android feature, or an unrestricted super-agent. It is the public-safe capability intelligence layer that converts operator intent into recommendations, governed workflows, automation proposals, and execution-ready receipts.

## Civic route

```text
Operator intent
  -> HERMES Dispatch
  -> SUPER HERMES Capability Intelligence Office
  -> stratified Skill / Tool / Resource index
  -> Model Council + MCP Registry
  -> Policy Gate
  -> governed workflow
  -> automation proposal
  -> approved execution lane
  -> validation + receipt
```

## Stratified index

| Temperature | Meaning | Execution status |
|---|---|---|
| Cold | Searchable catalog entry with provenance metadata | Never automatically executable |
| Warm | Evaluated, cached, and policy-compatible | Available for mission selection |
| Hot | Small mission-scoped capability set | Eligible only inside bounded approved execution |

The index covers:

- **Skills** — procedural contracts defining how work is performed.
- **Tools** — callable connectors, runtimes, sandboxes, and registries.
- **Resources** — models, policies, datasets, workflow templates, and infrastructure lanes.

## User output

A user states an outcome in ordinary language. SUPER HERMES returns:

1. Recommended capabilities with explainable fit scores.
2. The owning HERMES CITY district or institution.
3. A bounded workflow with checkpoints and fallbacks.
4. Suggested recurring or conditional automations.
5. Risk, trust, provenance, and temperature classifications.
6. A portable planning receipt.

The public interface recommends and plans. It does not independently grant authority, expose credentials, spend funds, merge protected branches, or execute irreversible actions.

## Thermodynamic observability

SUPER HERMES tracks routing entropy, capability drift, dependency drift, token and compute energy, retries, latency, cost, useful-work ratio, and automation authority creep.

A capability that consumes increasing energy while producing declining verified work is degraded or quarantined.
