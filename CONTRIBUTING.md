# Contributing to HERMES CITY

HERMES CITY accepts public-safe contributions to documentation, accessibility, interface quality, non-sensitive schemas, visual polish, and bounded prototypes.

## Before contributing

1. Open an issue describing the change and its public value.
2. Confirm the work contains no credentials, client data, proprietary prompts, private runtime logic, or unapproved brand assets.
3. Keep contributions within the public-shell boundary.
4. Add or update documentation and tests where applicable.

## Pull request requirements

- Explain the purpose and affected routes.
- State the security and privacy impact.
- Confirm mobile and keyboard behavior.
- Confirm no secrets or production endpoints were introduced.
- Preserve provenance and attribution.

Authority, production access, and district permissions are not granted by contribution alone. They require separate AGENTROPOLIS governance and approval.
