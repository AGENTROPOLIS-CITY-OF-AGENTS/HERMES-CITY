# Hermes Pattern Registry

Status: PROVISIONAL
Authority: EXECUTE (operator-approved)
Source class: external community evidence
Canonical owner: HERMES-CITY
Verification owner: VERITY
Policy owner: AEGIS

## Purpose

This registry converts publicly observed Hermes Agent user stories into governed AGENTROPOLIS implementation patterns.

It does **not** treat community behavior as canon, production readiness, authorization, or trusted skill state.

Core rule:

> Community pattern != trusted skill.
> Installed != loaded != live != authorized.
> Recommendation != execution authority.
> Successful once != production ready.

## AGENTROPOLIS processing corridor

External story
-> ingest membrane
-> evidence record
-> pattern normalization
-> VERITY review
-> AEGIS risk classification
-> capability/credential mapping
-> skill candidate
-> isolated test
-> signed evaluation receipt
-> Skill Registry promotion
-> Hermes fleet distribution

No source story can directly grant tool access, credentials, production authority, financial authority, or deployment authority.

## Promotion states

OBSERVED -> NORMALIZED -> REVIEWED -> TESTED -> VERIFIED -> SIGNED -> AUTHORIZED

A pattern may stop at any stage. No automatic promotion is permitted.

## Risk bands

- R0: read-only formatting / retrieval
- R1: reversible local workspace actions
- R2: authenticated external writes with bounded scope
- R3: consequential business, deployment, account, financial, or identity actions
- R4: prohibited or human-only actions

R3 requires explicit policy gates, scoped credentials, evidence, receipt, and independent review. Financial signals remain evidence and never become orders by inference.
