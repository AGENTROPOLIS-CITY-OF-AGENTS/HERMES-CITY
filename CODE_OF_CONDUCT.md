# Community Code of Conduct

HERMES Community is a technical and civic collaboration space. Participants must be respectful, evidence-aware, privacy-preserving, and honest about capabilities and limitations.

Unacceptable conduct includes harassment, discrimination, impersonation, doxxing, credential sharing, deceptive claims, malicious code, bypassing approval gates, or pressuring contributors to expose private systems.

Project maintainers may remove content, reject contributions, restrict participation, or escalate security concerns when needed to protect participants and the AGENTROPOLIS boundary.

Report sensitive conduct through private repository reporting channels rather than public issues.
